# MAINT-AI Lite — 컨셉 확정서

**대회:** 제8회 공군 창의·혁신 아이디어 공모 해커톤  
**분야:** 지정공모 (군수①) AI 기반 항공기 정비관리업무 자율화·자동화  
**확정일:** 2026-06-09

---

## 확정 컨셉

**「MAINT-AI Lite」** — 폐쇄망 환경 지능형 정비 행정·분석 플랫폼

### 핵심 문제 (Core Problem)

> 국방 폐쇄망(체계 간 연동 제한) 환경에서 정비 데이터의 수기 입력·엑셀 분석으로 발생하는 **인력 낭비**와, 정비사 숙련도 차이에 따른 **결함 분석 오류**를 해결하기 위해, OCR·로컬 LLM 기반의 자율형 정비 업무 플랫폼을 안전하게 구축하는 문제

### 스코프 제한 (실현가능성 확보)

- **포함:** 비행단 내 소모성 정비 부품(CAD/PAD), 군수 행정 프로세스, 조종사 Write-up 해석
- **제외:** 항공기 전체 디지털 트윈, 로봇·하드웨어(군수②), 출입통제(기지방호)

---

## 3 Pillar 구조

| Pillar | 기능 | 핵심 기술 |
|--------|------|----------|
| **1. 데이터화** | 수기 정비기록지 → DELIIS 정형 데이터 | LayoutLM v3, Diffusion 전처리, OCR |
| **2. 지식 추론** | Write-up → 결함코드 → 정비 가이드 | 로컬 sLLM + RAG, Vector DB |
| **3. 예측 알람** | CAD/PAD 시한품목 선제 교체 알림 | LSTM/Transformer, RAM 대시보드 |

### 로드맵 2단계 (PoC 이후)

- 동적 정비 스케줄링 (OR + 강화학습, Gantt 시뮬레이션)
- 마이크로 정비 지식 Wiki (NFC/QR + 현장 팁)
