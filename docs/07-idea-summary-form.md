## 1. 추진목표

※ 과제 성과 달성을 위한 주요목표 제시

ㅇ **국방 폐쇄망 환경에서 정비 업무 AI 자동화 체계 구축**
- 수기·엑셀 기반 정비 행정의 인력 낭비를 해소하고, 정비사 숙련도 격차에 따른 결함 분석 오류를 AI로 표준화

ㅇ **DELIIS 연계형 정비 데이터 일원화 달성**
- 수기 정비기록지 OCR 자동화 및 Write-up AI 해석을 통해 군수통합정보체계(DELIIS) 호환 정형 데이터 자동 생성·연계율 **80% 이상** 달성

ㅇ **결함 대응 속도·정확도 향상**
- 조종사 Write-up 입력 후 **3초 이내** 정비 가이드·체크리스트 자동 생성, 결함 오진율 **30% 감소**, 초보 정비사 TAT **20% 단축**

ㅇ **시한품목(CAD/PAD) 안전 관리 자동화**
- Shelf Life 기반 선제 알람 체계로 교체 누락·조기교체 **40% 감소**, RAM(신뢰도·가용도·정비도) 지표 실시간 관리

ㅇ **현장 정비 지식 보존·계승**
- QR/NFC 장비 태그 연동 정비 Wiki로 고참 현장 노하우의 기록·공유 체계 확립

## 2. 개발/구축내용

※ 개발/구축대상 범위 및 구축내용

ㅇ **(군수①) 국방 폐쇄망 최적화 AI 기반 항공기 정비관리 자율화·자동화 체계(MAINT-AI Lite) 구축**
- 비행단 내 **소모성 정비 부품(CAD/PAD) 및 군수 행정 프로세스**를 대상으로 지능형 정비 업무 플랫폼 구축
- 부대 내 **온프레미스 AI 서버 + 태블릿/웹 단말** 설치·운영, 민간 클라우드 AI 연동 없이 자율 운용

ㅇ **Pillar 1 — 수기 정비자료 AI 데이터화 및 DELIIS 자동 매핑**
- 태블릿 카메라 촬영 → **OCR·LayoutLM v3** 인식 → DELIIS 정형 데이터 자동 변환
- Diffusion 화질 복원 전처리, Human-in-the-loop 확인 UI 적용

ㅇ **Pillar 2 — 조종사 Write-up AI 해석 및 정비 가이드 자동 생성** *(데모 메인)*
- **로컬 sLLM + RAG** 기반 Write-up → 결함코드·TO 페이지·체크리스트·예상 TAT 자동 생성
- 기술도서(PDF) 및 과거 결함 이력 Vector DB 인덱싱

ㅇ **Pillar 3 — 시한품목(CAD/PAD) 수명 주기 예측 및 선제 알람**
- 사출좌석·채프/플레어·신관 등 Shelf Life 품목 기체별 이력 통합
- **LSTM/Transformer** 시계열 예측, D-Day 7일/3일/당일 선제 알림, RAM 대시보드

ㅇ **부가 — 정비 Wiki (QR/NFC 장비 태그 연동)**
- 장비별 현장 노하우 기록·조회·추가, 전출 시 지식 증발 방지

## 3. 기술요구사항

※ 기술구현 요소별 목표성능/규격

ㅇ **OCR·문서 AI**
- 수기 정비기록지 OCR 인식률 **95% 이상** (군수 지정 서식, Few-shot)
- DELIIS 필드 자동 매핑 정확도 **90% 이상**
- 1장 촬영 → 매핑 결과 출력 **5초 이내**

ㅇ **RAG·로컬 sLLM 정비 Copilot**
- Write-up → 결함코드 매핑 정확도 **85% 이상** (Top-3 기준)
- AI 응답 생성 속도 **3초 이내**, TO 페이지 검색 Recall@5 **90% 이상**
- **온프레미스 전용** — 외부망 API 호출 금지, 폐쇄망 단독 구동

ㅇ **시한품목 예측·알람**
- CAD/PAD 교체 시기 예측 정확도 **90% 이상** (D-Day ±3일)
- RAM 지표 **실시간** 갱신

ㅇ **플랫폼·인프라**
- 국방 **폐쇄망(망분리)** 온프레미스 배포, 정비사 **50명 이상** 동시 접속
- 가용성 **99.5% 이상**, 데이터 **AES-256** 암호화, 감사 로그 전수 기록
- DELIIS 스키마 호환 JSON API (PoC: 모의 DB → 시범: 실연동)

## 4. 개발기술특징

※ 중점 기술개발분야 및 주요특징

ㅇ **폐쇄망 특화 로컬 AI (인공지능)**
- 민간 클라우드 LLM 대신 **부대 내 sLLM(Llama/Qwen) + RAG** 온프레미스 구동
- 국방 데이터 보안 정책 준수하면서 생성형 AI 정비 보조 실현

ㅇ **Write-up → 결함코드 표준화 (빅데이터·SW)**
- 비정형 조종사 보고와 정형 기술도서 간 **의미 매핑** — 단순 챗봇이 아닌 정비 워크플로우 자동화
- 과거 결함 이력·TO 문서 Vector DB 통합 검색

ㅇ **군수 특화 Document AI (인공지능)**
- LayoutLM v3 + Diffusion 전처리로 **오염·필체·국방 약어** 대응 OCR
- 범용 OCR 대비 군수 서식 인식률 **15%p 이상** 개선 목표

ㅇ **좁고 깊은 스코프의 실현가능성 (스마트플랫폼)**
- 항공기 전체 MRO가 아닌 **소모품·행정** 집중 → 6개월 PoC·시범 도입 가능
- **웹 PoC 완료** (Write-up·OCR·시한품목·Wiki 4기능 시연)

ㅇ **현장 지식 디지털 자산화 (모바일·SW)**
- QR/NFC 장비 태그 + Wiki로 TO에 없는 **선임 노하우** 보존·계승

## 5. 체계구축/운영개념

※ 구축개념 및 운영개념

ㅇ **구축 개념 (3계층 아키텍처)**

```
[단말 계층]  태블릿/웹 앱 (정비사·관리자 UI)
      ↕ REST API (폐쇄망 내부)
[AI 계층]    온프레미스 GPU 서버 — OCR / RAG+sLLM / 예측 알람
      ↕ 스키마 호환 API
[데이터 계층] DELIIS 연계 DB · 기술도서 · 결함이력 · 시한품목 DB
```

ㅇ **운영 개념**
- **폐쇄망 단독 운용**: 외부 인터넷 차단 상태에서 부대 내 완결 운영
- **Human-in-the-loop**: OCR·AI 추론 결과는 정비사 최종 확인 후 DELIIS 반영
- **단계적 도입**: PoC(3개월) → 1개 비행단 시범(1년) → 전단 확산(2년+)
- **역할 분담**: 정비사(현장 입력·확인) / 관리자(시한품목·RAM 모니터링) / AI 서버(자동 추론·알람)

ㅇ **보안 운영**
- 감사 로그 전수 기록, 전송·저장 AES-256 암호화
- AI 모델·화이트리스트 DB 온프레미스 상주, 외부 API 미사용

## 6. 기대효과

※ 경제성, 효율성, 병력절감 등 유·무형 효과

ㅇ **병력절감·업무 효율 (유형)**
- 정비 보고서 작성 시간: 45분/건 → **18분/건** (**60% 감소**)
- 엑셀 수기 분석·입력 병력 **30% 이상** 절감 (1개 비행단 기준)
- 초보 정비사 TAT(정비 소요시간) **20% 단축** → 숙련 정비사 의존도 감소

ㅇ **정비 품질·안전 (무형)**
- Write-up AI 표준 가이드 적용으로 결함 **오진율 30% 감소**
- CAD/PAD 교체 누락·조기교체 **40% 감소** → 안전 리스크·자원 낭비 동시 해소
- RAM 지표 실시간 관리로 기체 **가동률(Availability) 향상**

ㅇ **지식·조직 역량 (무형)**
- 정비 Wiki로 고참 노하우 **디지털 보존** → 전출·전역 시 지식 공백 최소화
- DELIIS 데이터 연계율 **80% 이상** → 데이터 기반 정비 의사결정 체계 정착

ㅇ **경제성**
- 조기·지연 교체로 인한 **부품 낭비비용 절감**
- 오진에 따른 불필요 정비 공수·부품 교체 비용 절감
- 민간 클라우드 AI 미사용으로 **라이선스·망연계 비용 절감** (온프레미스 1회 구축)
