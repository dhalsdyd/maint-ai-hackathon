# 차별점·중복 검토표

## 1. DELIIS·공군 기적용 사항과의 차별

| 항목 | DELIIS (As-Is) | MAINT-AI Lite (To-Be) | 차별점 |
|------|---------------|----------------------|--------|
| 데이터 입력 | 수동 입력·단순 축적 | OCR 자동 매핑 + Write-up AI 해석 | **입력 자동화** |
| 분석 | 운용자 숙련도 의존 | RAG 표준 가이드 + 결함코드 매핑 | **분석 표준화** |
| 예측 | 미흡 | CAD/PAD 시한품목 선제 알람 | **예측·알람** |
| AI 연동 | 민간 AI 직접 연동 불가 | 온프레미스 sLLM 설계 | **폐쇄망 호환** |

**중복 여부:** DELIIS는 **데이터 저장·관리 체계**, MAINT-AI는 **AI 기반 입력·분석·예측 레이어** → 상위 보조 체계로 포지셔닝, 중복 아님.

## 2. 공군 해커톤 과거 수상작 대비

| 수상작 유형 (일반적) | MAINT-AI Lite 차별 |
|--------------------|-------------------|
| 일반 정비 Copilot/챗봇 | **Write-up→결함코드 표준화** 구체 Pain |
| 항공기 전체 디지털 트윈 | **소모품·행정** 좁은 스코프 |
| 클라우드 AI 솔루션 | **폐쇄망 로컬 sLLM** |
| 단일 기능 (OCR만, RAG만) | **3 Pillar 통합** end-to-end |
| 기획서만 제출 | **Flutter 태블릿 PoC** 실증 |

**중복 방지 전략:** Write-up 매핑 + 시한품목 알람 + DELIIS 연동 설계 **3요소 조합**은 기존 단일 기능 수상작과 차별.
