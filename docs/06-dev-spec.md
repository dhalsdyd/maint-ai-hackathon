# 개발/구축내용 · 기술요구사항 (기획서 양식)

## □ 개발/구축내용
※ 개발/구축대상 범위 및 주요내용 기술

ㅇ **(군수①) 국방 폐쇄망 환경에 최적화된 AI 기반 항공기 정비관리 자율화·자동화 체계(MAINT-AI Lite) 구축**

- 비행단 내 **소모성 정비 부품(CAD/PAD) 및 군수 행정 프로세스**를 대상으로, 수기·엑셀 기반 정비 업무를 AI로 자동화하는 지능형 정비 업무 플랫폼 구축
- **군수통합정보체계(DELIIS) 스키마 호환** 설계를 통해 정비 데이터의 수집·정형화·분석·예측을 일원화
- **완전 폐쇄망(온프레미스) 구동** 방식으로 부대 내 전용 AI 서버 및 태블릿 단말기를 설치·운영하여 민간 클라우드 AI 연동 없이 자율 운용

ㅇ **Pillar 1 — 수기 정비자료 AI 데이터화 및 DELIIS 자동 매핑 체계 구축**

- 정비 현장 수기 정비기록지·엑셀 파일을 태블릿 카메라 촬영 후 **OCR·LayoutLM 기반 자동 인식**하여 DELIIS 정형 데이터로 변환
- 오염·필체 차이·국방 약어 등 현장 특수 환경에 대응하는 **화질 복원 전처리 및 서식 맵퍼** 적용
- Human-in-the-loop 확인 UI를 통해 오인식 데이터의 수동 보정 후 DELIIS 연계 입력

ㅇ **Pillar 2 — 조종사 Write-up AI 해석 및 정비 가이드 자동 생성 체계 구축**

- 조종사 결함 보고(Write-up) 비정형 텍스트를 **로컬 sLLM + RAG(검색증강생성)** 기술로 기술도서(TO) 결함코드에 자동 매핑
- 기술도서(PDF) 및 과거 결함 이력을 Vector DB로 인덱싱하여 **정비 체크리스트·권장 수리방안·예상 TAT** 자동 생성
- 정비사 태블릿 앱을 통한 대화형 UI 제공 및 현장 작업 모드(햅틱 알림) 지원

ㅇ **Pillar 3 — 시한품목(CAD/PAD) 수명 주기 예측 및 선제 알람 체계 구축**

- 사출좌석 부품, 채프/플레어, 미사일 신관 등 **Shelf Life 관리 대상 품목**의 기체별 장착 이력 통합 관리
- 시계열 예측 모델(LSTM/Transformer) 기반 **교체 시기 선제 알람** 및 RAM(신뢰도·가용도·정비도) 지표 대시보드 제공
- 엑셀 파편화로 인한 교체 누락·조기교체 방지를 위한 **D-Day 알림 및 주간 교체 대상 자동 산출**

ㅇ **(로드맵 2단계) 동적 정비 스케줄링 및 현장 지식 공유 체계 확장**

- 돌발 결함·비행일정 변경 시 **정비사 자격급수·가용 정비고·수리부속 재고** 3대 제약조건 기반 실시간 스케줄 최적화
- NFC/QR 기반 **마이크로 정비 지식 Wiki**를 통해 고참 현장 노하우의 기록·공유·계승 지원

## □ 기술요구사항
※ R&D, 기술구현 요소별 목표성능/규격 등

ㅇ **OCR·문서 AI 목표 성능**

| 항목 | 목표 성능/규격 |
|------|---------------|
| 수기 정비기록지 OCR 인식률 | **95% 이상** (군수 지정 서식 기준, Few-shot 학습 적용) |
| 필드 자동 매핑 정확도 | **90% 이상** (DELIIS 스키마 필드 대비) |
| 화질 복원 전처리 | 오염·흐림 문서 대비 인식률 **15%p 이상** 개선 |
| 처리 속도 | 1장 촬영 → DELIIS 매핑 결과 출력 **5초 이내** |
| 적용 기술 | LayoutLM v3, Diffusion 기반 화질 복원, Few-shot 파인튜닝 |

ㅇ **RAG·로컬 sLLM 정비 Copilot 목표 성능**

| 항목 | 목표 성능/규격 |
|------|---------------|
| Write-up → 결함코드 매핑 정확도 | **85% 이상** (기술도서 대비 Top-3 추천 기준) |
| AI 응답 생성 속도 | 증상 입력 → 정비 가이드 출력 **3초 이내** |
| 관련 TO 페이지 검색 정확도 | **90% 이상** (Recall@5 기준) |
| 오진율(엉뚱한 부품 점검) 감소 | 기존 대비 **30% 이상** 감소 |
| 적용 기술 | 로컬 sLLM (Llama 3 / Qwen 2, 7B~13B), RAG, Vector DB (FAISS/Milvus) |
| 보안 요구 | **온프레미스 전용** — 외부망 API 호출 금지, 폐쇄망 단독 구동 |
